Update Qty Sale.

The moment a sale order is confirmed, the module automatically finds each ordered product and immediately subtracts its quantity from main warehouse stock, bypassing the delivery/shipment validation step entirely.

Key Features:

  • Instant Stock Deduction on Sale Confirmation:When a sale order is confirmed the module loops through every order line, identifies the product and ordered quantity, and deducts it directly from main warehouse stock using a negative quantity update. This means the available stock count drops immediately when a sale is confirmed.
